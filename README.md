# CryoManager — Semex

Sistema de controle de testes de botijões criogênicos.

## Objetivo
Organizar o registro e o acompanhamento dos testes dos botijões, incluindo medições de 24 e 48 horas, responsáveis e resultados.

## Funcionalidades
- Cadastro e consulta de botijões.
- Registro de testes e medições.
- Classificação manual dos resultados como APTO ou INAPTO.
- Histórico de testes.
- Notificações e lembretes.

## Status do projeto
Protótipo acadêmico com dados simulados, desenvolvido para a disciplina de Projeto de Software.
